# DevOps Team Standup and Sprint Intelligence Discord Bot

A Discord bot purpose-built for DevOps and engineering teams that automates daily standups, tracks sprint velocity, surfaces deployment blockers, monitors on-call rotations, and posts CI/CD status updates directly in your team channels. Eliminate status meetings and keep your team in sync without leaving Discord.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
